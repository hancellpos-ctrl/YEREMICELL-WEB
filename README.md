# YEREMICELL — Web pública

Archivos públicos del catálogo de Yeremi Cell Import, adaptado para iPhone. Render sirve estos archivos. Las rutas de API y fotografías subidas se conectan al backend existente, que conserva los productos, las sesiones y las fotos.

Este repositorio contiene únicamente archivos que se sirven públicamente a los visitantes. No contiene contraseñas, claves de API ni datos privados del panel.

Construcción: `node build.mjs` (requiere `RENDER_EXTERNAL_URL` o `PUBLIC_SITE_URL`). Directorio publicado: `dist`.
